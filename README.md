# 周至猕猴桃 · 宣传站

**线上地址**：https://rubia01.github.io/zhouzhi-kiwi/
**仓库**：https://github.com/rubia01/zhouzhi-kiwi

纯静态单页品牌站，零构建、零依赖，双击 `index.html` 就能看。

**主题**：陕西 · 西安 · 周至 —— 秦岭北麓的"中国猕猴桃之乡"，品牌口号「周至猕猴桃 · 鲜甜自有道」。

站内有一个可拖拽旋转、能切开的 three.js 三维猕猴桃（第 04 区块"里与外"）。

---

## 打开方式

1. 直接双击 `index.html`（file:// 协议已验证可用，3D 部分也能正常工作）。
2. 或起个本地服务：

```bash
cd D:\myproject\ZMT
python -m http.server 8099
# 打开 http://127.0.0.1:8099
```

## 设计说明

- **配色**：深墨绿 `#0A1D14` — 果肉绿 `#8FBE52` — 米白 `#FBF8F0` — 点缀金 `#C29A48`。
- **字体**：中文标题走衬线（Noto Serif SC → 系统宋体回退），数字用 Cormorant Garamond，正文系统无衬线。字体走 `fonts.googleapis.cn` 异步加载，断网自动回落到系统字体，版式不塌。
- **动效**：滚动渐入（IntersectionObserver）、数字滚动、首屏视差、果盘呼吸、时间轴进度线、品种切换淡入。全部尊重 `prefers-reduced-motion`。
- **响应式**：1080 / 960 / 820 / 640 四档断点；移动端汉堡菜单、单列化、首屏大圆隐藏、3D 舞台居中。

## 3D 剖面的实现

- **模型**：两个 `SphereGeometry` 半球（`phiLength = π`）拼成一颗椭球，各配一片 `CircleGeometry` 作切面；切开时两半沿 x 轴分离并各自绕 y 轴侧转约 14°，同时整体缩小，保证两瓣都装进画面。
- **纹理全部程序生成**，没有外部贴图：
  - 果皮 = canvas 画绒毛（左右边界 wrap，避免球面 UV 接缝露馅）+ 噪点，同时用作 `bumpMap` 做凹凸；
  - 果肉 = canvas 径向渐变 + 900 条弯曲纤维 + 118 粒籽 + 切口果皮断面。
- **交互**：指针拖动带惯性旋转，空闲 2.6 秒后缓慢自转；点击（位移 < 6px 的短按）切开/合上；切开时暂停自转，保证切面正对镜头。
- **性能**：`IntersectionObserver` 离开视口即停止渲染；`devicePixelRatio` 上限 2；页面隐藏时停帧。
- **兜底**：不支持 WebGL 时显示静态 SVG 剖面图和一句说明，按钮置灰。

## 改东西的位置

- **文案**：全部在 `index.html`，按区块注释分段。
- **品种数据**：`assets/js/main.js` 里的 `V` 数组（名称、英文、标签、描述、成熟期、糖度、单果重、果肉色、色值、三项百分比）。
- **配色**：`assets/css/main.css` 顶部 `:root` 变量，改一处全站生效。
- **图片**：替换 `assets/img/` 同名文件即可，比例建议：首屏背景 3:2、配图 4:3。

### URL 参数（调试用）

- `?shot=1` —— 静态截图模式：跳过 loader、直接展开所有渐入元素、数字直出终值。
- `?v=0..4` —— 直接定位到某个品种（0 翠香 / 1 徐香 / 2 秦美 / 3 海沃德 / 4 瑞玉）。
- `?cut=1` —— 3D 猕猴桃加载时就是切开状态（可和 `?shot=1` 联用）。
